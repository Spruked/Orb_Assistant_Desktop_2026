# MORB Deployments

This folder is reserved for deployed MORB research, diagnostic, scan, repair-plan, and verification jobs.

Contract:

```text
R:\Orb_Assistant_Desktop\docs\MORB_RESEARCH_DIAGNOSTIC_DEPLOYMENT_CONTRACT.md
```

Folders:

```text
jobs\        MORB job manifests waiting to run.
active\      Running MORB deployment state.
results\     Completed MORB result artifacts.
archive\     Operator-approved retained MORB runs.
quarantine\  Rejected, malformed, or unsafe MORB outputs.
```

Desktop ORB presents and supervises deployed MORBs. MORBs perform research, diagnostics, scanning, and repair planning. Repair execution requires operator approval.
